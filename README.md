# AI Foundry Evaluation CI/CD

A comprehensive repository demonstrating how to implement Continuous Integration/Continuous Deployment (CI/CD) pipelines for evaluating AI agents using Azure AI Foundry and GitHub Actions.

## Overview

This repository provides sample implementations for automating AI agent evaluations using Azure AI Foundry's evaluation capabilities. It includes multiple approaches to run evaluations both locally and through GitHub Actions workflows, supporting both modern Azure AI Foundry and legacy Azure AI Hub environments.

## Repository Structure

### Python Scripts

#### 1. `aiCloudEvaluatorAIEvaluationSDK.py`
Demonstrates cloud-based AI evaluation using the Azure AI Evaluation SDK. This script:
- Loads Azure credentials from environment variables
- Configures Azure OpenAI model settings
- Runs evaluations using `GroundednessEvaluator` and `SimilarityEvaluator`
- Processes data from `sample.jsonl` file
- Uploads evaluation results to Azure AI Foundry project
- Outputs results to `myevalresults.json`

**Key Features:**
- Environment variable-based configuration
- Column mapping for evaluator inputs
- Azure AI project integration for result tracking
- JSON output for evaluation metrics

#### 2. `aiLOCALevaluator.py`
Comprehensive local evaluation script that demonstrates AI agent creation and evaluation. This script:
- Creates an AI agent using Azure AI Projects client
- Establishes agent communication threads
- Processes agent runs and responses
- Converts agent interactions to evaluation format using `AIAgentConverter`
- Applies multiple quality and safety evaluators including:
  - **Quality Evaluators**: IntentResolution, TaskAdherence, ToolCallAccuracy, Coherence, Fluency, Relevance
  - **Safety Evaluators**: ContentSafety, IndirectAttack, CodeVulnerability
- Supports reasoning models (e.g., o3-mini) for advanced evaluation

**Key Features:**
- Full agent lifecycle demonstration (create, thread, message, run)
- Azure CLI credential authentication
- Separation of reasoning and standard model configurations
- Comprehensive quality and safety evaluation suite
- JSON-formatted evaluation results output

#### 3. `aiCloudEvaluator.py`
Empty placeholder file for future cloud evaluator implementations.

### GitHub Actions Workflows

Located in `.github/workflows/`, these workflows automate AI agent evaluations:

#### 1. `aiPythonEvalSDK.yml` - AI Agent Python Evaluation SDK
- **Trigger**: Manual workflow dispatch
- **Purpose**: Runs cloud-based evaluation using Python SDK
- **Features**:
  - Uses Azure Federated Credentials for authentication
  - Python 3.13 environment
  - Installs dependencies from `requirements.txt`
  - Executes `aiCloudEvaluatorAIEvaluationSDK.py`
  - Configurable via GitHub variables and secrets

#### 2. `aifoundryeval.yml` - Modern AI Foundry Evaluation
- **Trigger**: Manual workflow dispatch
- **Purpose**: Evaluates AI agents using the modern Azure AI Foundry (v2-beta)
- **Features**:
  - Uses `microsoft/ai-agent-evals@v2-beta` action
  - Python 3.10 environment
  - Evaluates specific agent IDs
  - Reads test data from `datafile.json`
  - Direct integration with Azure AI Foundry projects

#### 3. `aihubeval.yml` - Legacy AI Hub Evaluation
- **Trigger**: Manual workflow dispatch
- **Purpose**: Evaluates AI agents using legacy Azure AI Hub (v1-beta)
- **Features**:
  - Uses `microsoft/ai-agent-evals@v1-beta` action
  - Supports legacy Azure AI Hub connection strings
  - Backward compatibility for older deployments

### Data Files

#### 1. `datafile.json`
Structured test data file containing:
- Test dataset name: "MyTestData"
- List of evaluators to apply:
  - RelevanceEvaluator
  - ViolenceEvaluator
  - HateUnfairnessEvaluator
  - IntentResolutionEvaluator
  - TaskAdherenceEvaluator
  - ToolCallAccuracyEvaluator
  - CoherenceEvaluator
  - FluencyEvaluator
  - GroundednessEvaluator
- Sample queries with context and ground truth data
- Includes edge cases for safety testing (e.g., inappropriate content detection)

#### 2. `sample.jsonl`
JSON Lines format file containing evaluation test cases. Each line represents a test case with:
- `query`: User question or prompt
- `ground_truth`: Expected correct response
- `response`: Actual AI agent response
- `context`: Background information provided to the agent
- `latency`: Response time metrics
- `response_length`: Length of the generated response

**Example domains covered:**
- Health insurance provider selection
- Travel booking queries
- Information retrieval and comparison tasks

#### 3. `myevalresults.json`
Output file generated by evaluation runs, containing:
- Metric summaries
- Row-level evaluation data
- Links to Azure AI project results
- Detailed scoring for each evaluator

## Prerequisites

### Azure Resources Required:
- Azure AI Foundry project or Azure AI Hub workspace
- Azure OpenAI deployment(s)
- Azure CLI installed (for local execution)
- Proper RBAC permissions for AI services

### GitHub Configuration:
- **Variables** (set in repository settings):
  - `AZURE_API_VERSION`: Azure OpenAI API version
  - `AZURE_DEPLOYMENT_NAME`: Name of the OpenAI deployment
  - `AZURE_ENDPOINT`: Azure OpenAI endpoint URL
  - `AZURE_AI_PROJECT`: Azure AI project endpoint
  - `AZURE_CLIENT_ID`: Azure service principal client ID
  - `AZURE_TENANT_ID`: Azure tenant ID
  - `AZURE_SUBSCRIPTION_ID`: Azure subscription ID
- **Secrets**:
  - `AZURE_API_KEY`: Azure OpenAI API key

## Usage

### Running Locally

1. **Set up environment variables:**
   ```bash
   export AZURE_DEPLOYMENT_NAME="your-deployment"
   export AZURE_API_KEY="your-api-key"
   export AZURE_ENDPOINT="your-endpoint"
   export AZURE_API_VERSION="2024-02-01"
   export AZURE_AI_PROJECT="your-project-url"
   export MODEL_DEPLOYMENT_NAME="your-model"
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Authenticate with Azure CLI:**
   ```bash
   az login
   ```

4. **Run evaluations:**
   ```bash
   # Cloud evaluation with SDK
   python aiCloudEvaluatorAIEvaluationSDK.py
   
   # Local agent evaluation
   python aiLOCALevaluator.py
   ```

### Running via GitHub Actions

1. Navigate to the **Actions** tab in your GitHub repository
2. Select one of the available workflows:
   - AI Agent Python Evaluation SDK
   - AI Agent Evaluation Modern AI Foundry
   - AI Agent Evaluation Legacy AI Hub
3. Click **Run workflow**
4. View results in the workflow run logs and Azure AI Foundry portal

## Evaluation Metrics

The repository demonstrates various AI evaluation metrics:

### Quality Metrics:
- **Groundedness**: Measures if responses are based on provided context
- **Relevance**: Evaluates response relevance to the query
- **Coherence**: Assesses logical flow and consistency
- **Fluency**: Measures language quality and readability
- **Similarity**: Compares response similarity to ground truth
- **Intent Resolution**: Checks if user intent is properly addressed
- **Task Adherence**: Evaluates if the agent follows instructions
- **Tool Call Accuracy**: Measures correct tool usage

### Safety Metrics:
- **Content Safety**: Detects harmful content
- **Violence Detection**: Identifies violent content
- **Hate/Unfairness**: Detects bias and discriminatory content
- **Indirect Attacks**: Identifies prompt injection attempts
- **Code Vulnerability**: Finds security issues in generated code
